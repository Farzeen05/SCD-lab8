\# Lab 08 – OOP in Java: Aggregation vs Composition (FleetOps)



Course: Software Construction | UET Abbottabad Campus | Fall 2026



\## Task description

\- Task 1: Maven project setup with .gitignore

\- Task 2: Aggregation (Driver, FleetDepot, Vehicle)

\- Task 3: Composition with defensive copying (Engine, MaintenanceLog, Vehicle)

\- Task 4: FleetVerificationDriver, which tests lifecycle independence and encapsulation



\## How to run

1\. Open the project in Apache NetBeans (Java 17, Maven).

2\. Right-click `FleetVerificationDriver.java` and choose Run File.



Or from a terminal:

mvn compile exec:java -Dexec.mainClass="com.uet.construction.fleetops.FleetVerificationDriver"
